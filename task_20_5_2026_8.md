## Part 1 — New Models

### `models/crm.py` (new file)

```python
from datetime import datetime
from typing import Optional
from sqlalchemy import Integer, String, Text, Boolean, Numeric, DateTime, Date, ForeignKey
from sqlalchemy.orm import Mapped, mapped_column
from .user import Base


class CRMStage(Base):
    __tablename__ = "crm_stages"

    id:           Mapped[int]  = mapped_column(Integer, primary_key=True)
    workspace_id: Mapped[int]  = mapped_column(ForeignKey("workspaces.id"), nullable=False, index=True)
    name:         Mapped[str]  = mapped_column(String(128), nullable=False)
    sequence:     Mapped[int]  = mapped_column(Integer, default=10)
    probability:  Mapped[float] = mapped_column(Numeric(5, 2), default=10.0)
    is_won:       Mapped[bool] = mapped_column(Boolean, default=False)


class CRMLead(Base):
    __tablename__ = "crm_leads"

    id:               Mapped[int]            = mapped_column(Integer, primary_key=True)
    workspace_id:     Mapped[int]            = mapped_column(ForeignKey("workspaces.id"), nullable=False, index=True)
    name:             Mapped[str]            = mapped_column(String(256), nullable=False)
    partner_name:     Mapped[Optional[str]]  = mapped_column(String(256), nullable=True)
    email_from:       Mapped[Optional[str]]  = mapped_column(String(256), nullable=True)
    phone:            Mapped[Optional[str]]  = mapped_column(String(64),  nullable=True)
    stage_id:         Mapped[Optional[int]]  = mapped_column(ForeignKey("crm_stages.id"), nullable=True)
    priority:         Mapped[str]            = mapped_column(String(1), default='0')  # '0'–'3'
    expected_revenue: Mapped[float]          = mapped_column(Numeric(14, 2), default=0)
    probability:      Mapped[float]          = mapped_column(Numeric(5, 2), default=10)
    user_id:          Mapped[Optional[int]]  = mapped_column(ForeignKey("users.id"), nullable=True)
    description:      Mapped[Optional[str]]  = mapped_column(Text, nullable=True)
    date_deadline:    Mapped[Optional[str]]  = mapped_column(String(10), nullable=True)  # 'YYYY-MM-DD'
    is_won:           Mapped[bool]           = mapped_column(Boolean, default=False)
    is_active:        Mapped[bool]           = mapped_column(Boolean, default=True)
    created_at:       Mapped[datetime]       = mapped_column(DateTime, default=datetime.utcnow)
    updated_at:       Mapped[datetime]       = mapped_column(DateTime, default=datetime.utcnow)
```

### Helper — `_lead_to_out(lead, stage, user) → dict`

```python
def _lead_to_out(lead, stage=None, user=None):
    return {
        "id": lead.id,
        "name": lead.name,
        "partner_name": lead.partner_name,
        "email_from": lead.email_from,
        "phone": lead.phone,
        "stage_id": [stage.id, stage.name] if stage else None,
        "priority": lead.priority,
        "expected_revenue": float(lead.expected_revenue or 0),
        "probability": float(lead.probability or 0),
        "date_deadline": lead.date_deadline,
        "is_won": lead.is_won,
        "description": lead.description,
        "user_id": [user.id, user.name] if user else None,
        "activity_state": None,
        "activity_date_deadline": None,
        "activity_type_id": None,
    }
```

### Endpoints

```
GET /crm/stages
    Where: workspace_id == ws
    Order: sequence ASC
    Returns list[StageOut]
    Side effect: if workspace has NO stages yet, auto-seed 5 default stages:
        New (seq=10), Qualified (seq=20), Proposition (seq=30),
        Won (seq=40, is_won=True, prob=100), Lost (seq=50, prob=0)

POST /crm/stages
    Body: {name, sequence?, probability?, is_won?}
    Returns: StageOut (201)

GET /crm/leads
    Where: workspace_id == ws, is_active == True
    Order: created_at DESC
    Returns list (built with _lead_to_out, load stage+user for each lead)

POST /crm/leads
    Body: LeadCreate
    If no stage_id provided, use the first stage (lowest sequence) in workspace
    Returns: LeadOut (201)

GET /crm/leads/{lead_id}
    404 if not found or wrong workspace
    Returns: _lead_to_out with stage and user loaded

PATCH /crm/leads/{lead_id}
    Accept LeadUpdate
    Note: frontend sends active=False for "Lost" → set is_active=False
    Note: frontend sends is_won=True for "Won"
    Update updated_at = datetime.utcnow()
    Returns: LeadOut

DELETE /crm/leads/{lead_id}
    Soft delete: is_active = False
    Returns: 204

GET /crm/stats
    Returns:
    {
      "total": count of active leads in workspace,
      "won": count where is_won == True,
      "in_progress": count where is_won == False,
      "total_revenue": sum(expected_revenue) where is_won == True,
      "pipeline_value": sum(expected_revenue) of all active leads
    }
```

## Auto-seed Logic (important)

On `GET /crm/stages`, if the workspace has zero stages, create 5 default stages:

| name | sequence | probability | is_won |
|------|----------|-------------|--------|
| New | 10 | 10 | False |
| Qualified | 20 | 30 | False |
| Proposition | 30 | 60 | False |
| Won | 40 | 100 | **True** |
| Lost | 50 | 0 | False |

This ensures the Pipeline view always has something to show, and new leads get a valid stage_id
from the first call.
