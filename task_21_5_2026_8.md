## What `api/client.js` Is

`frontend/src/api/client.js` is the real axios instance with:
- `baseURL` from `VITE_API_BASE_URL` env var or `/api`
- `Authorization: Bearer <token>` request interceptor
- 401 auto-refresh interceptor (retries with refresh token, redirects to `/login` on failure)

It is the correct and only api client for the web frontend.
