```python
    name:         Mapped[str]           = mapped_column(String(128), nullable=False)
    color:        Mapped[str]           = mapped_column(String(16), default='#2196F3')
    max_days:     Mapped[int]           = mapped_column(Integer, default=30)
    is_active:    Mapped[bool]          = mapped_column(Boolean, default=True)


class LeaveRequest(Base):
    __tablename__ = "leave_requests"

    id:              Mapped[int]           = mapped_column(Integer, primary_key=True)

    user_id:         Mapped[int]           = mapped_column(ForeignKey("users.id"), nullable=False, index=True)
    leave_type_id:   Mapped[Optional[int]] = mapped_column(ForeignKey("leave_types.id"), nullable=True)

    date_to:         Mapped[date]          = mapped_column(Date, nullable=False)
```

```python
_DEFAULT_LEAVE_TYPES = [
    {"name": "Casual Leave",  "color": "#2196F3", "max_days": 12},
    {"name": "Sick Leave",    "color": "#F44336", "max_days": 10},
    {"name": "Annual Leave",  "color": "#4CAF50", "max_days": 21},
]

async def _ensure_leave_types(ws_id: int, db: AsyncSession):
    result = await db.execute(
        select(LeaveType).where(LeaveType.workspace_id == ws_id, LeaveType.is_active == True).limit(1)
    )
    if result.scalar_one_or_none() is None:
        for lt in _DEFAULT_LEAVE_TYPES:
            db.add(LeaveType(workspace_id=ws_id, **lt))
        await db.flush()
```

### 3e. Replace stub leave endpoints with real implementations

**`GET /leave-types`**
```
Ensure leave types exist (auto-seed if none).
Return all active leave types for workspace.
```

**`GET /leaves`**
```
Where: workspace_id == ws, user_id == current_user.id
Order: created_at DESC
Load leave_type for each, return list via _leave_out()
```

**`POST /leaves`**
```
Body: {holiday_status_id: int|null, date_from: str, date_to: str|null, name: str|null}
date_to defaults to date_from if not provided
state = 'confirm' (submitted for approval)
Returns: _leave_out (201)
```

**`POST /leaves/{leave_id}/approve`** (admin/manager only)
```
Load request (workspace check), set state = 'validate', approved_by = current_user.id
Returns: _leave_out
```

**`POST /leaves/{leave_id}/refuse`** (admin/manager only)
```
Load request (workspace check), set state = 'refuse'
Returns: _leave_out
```

**`POST /leaves/{leave_id}/cancel`**
```
Load request, check user_id == current_user.id OR current_user.role == 'admin'
Only allow if state in ('draft', 'confirm')
Set state = 'draft' → effectively withdrawn (frontend shows this as cancelled)
Returns: _leave_out
```

**`GET /leaves/pending-approval`** (admin/manager)
```
Where: workspace_id == ws, state == 'confirm'
Order: created_at ASC
Returns: list (include user name — fetch User for each)
Shape: {..._leave_out(), "employee_name": user.name}
```
