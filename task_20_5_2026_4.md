#### Endpoint 1: `GET /gst/gstr1`
**Query params:** `month: int`, `year: int`

Logic:
1. Fetch all `sent`, `paid`, `overdue` invoices in the given month/year (`invoice_date` filter)
2. Split invoices into three GST categories:
   - **B2B** — `customer_gstin` is not null and not empty → grouped by customer GSTIN
   - **B2CS** — no GSTIN, `igst_total > 0` (inter-state), taxable value ≤ ₹250,000 per invoice → combined by state+rate
   - **B2CL** — no GSTIN, `igst_total > 0`, taxable value > ₹250,000 → detailed per invoice
   - **B2C (intra, no GSTIN)** — `igst_total == 0`, no GSTIN → grouped by rate in B2CS (intra-state B2C is always B2CS regardless of value)
3. Compute HSN summary — group `invoice_lines` by `hsn_code` + `gst_rate`, sum qty + taxable + GST
4. Compute totals across all invoices

Response shape:
```json
{
  "period": "05-2026",
  "gstin": "27AABCU9603R1Z0",
  "legal_name": "My Business Pvt Ltd",
  "b2b": [
    {
      "customer_gstin": "29AABCU9603R1Z0",
      "customer_name": "ABC Ltd",
      "invoices": [
        {
          "invoice_number": "INV-2026-00001",
          "invoice_date": "2026-05-10",
          "place_of_supply": "29",
          "taxable_value": 10000.0,
          "igst": 0.0, "cgst": 900.0, "sgst": 900.0,
          "total_tax": 1800.0
        }
      ]
    }
  ],
  "b2cs": [
    {"place_of_supply": "27", "gst_rate": 18.0, "taxable_value": 5000.0, "igst": 0.0, "cgst": 450.0, "sgst": 450.0}
  ],
  "b2cl": [],
  "hsn_summary": [
    {"hsn_code": "9983", "description": "", "uqc": "OTH", "qty": 5.0, "taxable_value": 15000.0, "igst": 0.0, "cgst": 1350.0, "sgst": 1350.0, "total_tax": 2700.0}
  ],
  "totals": {
    "taxable_value": 15000.0, "igst": 0.0, "cgst": 1350.0, "sgst": 1350.0, "total_tax": 2700.0
  }
}
```

#### Endpoint 2: `GET /gst/gstr3b`
**Query params:** `month: int`, `year: int`

Logic:
1. Fetch all sent/paid/overdue invoices for the period
2. Compute `3.1(a)` — Outward taxable supplies (other than zero/nil/exempt):
   - Sum `subtotal - discount_total` as `taxable_value`
   - Sum `cgst_total`, `sgst_total`, `igst_total`
3. ITC section — all zeros (no purchase/vendor bill data yet — leave as 0 with note)
4. Tax payable = output tax (no ITC offset for now)

Response shape:
```json
{
  "period": "05-2026",
  "outward_supplies": {
    "taxable_value": 15000.0,
    "igst": 0.0, "cgst": 1350.0, "sgst": 1350.0,
    "total_tax": 2700.0
  },
  "zero_rated": {"taxable_value": 0.0, "igst": 0.0},
  "nil_exempt": {"taxable_value": 0.0},
  "itc_available": {
    "igst": 0.0, "cgst": 0.0, "sgst": 0.0,
    "note": "ITC calculation requires vendor bills module (not yet implemented)"
  },
  "tax_payable": {
    "igst": 0.0, "cgst": 1350.0, "sgst": 1350.0, "cess": 0.0, "total": 2700.0
  },
  "interest_late_fee": {"interest": 0.0, "late_fee": 0.0}
}
```

#### Endpoint 3: `GET /gst/gstr1/export`
**Query params:** `month: int`, `year: int`

Same data as `GET /gst/gstr1` but returned as a downloadable JSON file:
```python
return Response(
    content=json.dumps(data, default=str),
    media_type="application/json",
    headers={"Content-Disposition": f"attachment; filename=GSTR1_{year}_{month:02d}.json"}
)
```

#### Endpoint 5: `GET /gst/reports/tax-summary`
**Query params:** `from_date: date`, `to_date: date`

Groups all sent/paid/overdue invoices in the date range by GST rate slab.

Response:
```json
{
  "from_date": "2026-05-01",
  "to_date": "2026-05-31",
  "by_rate": [
    {"gst_rate": 5.0,  "invoice_count": 2, "taxable_value": 10000.0, "cgst": 250.0, "sgst": 250.0, "igst": 0.0, "total_tax": 500.0},
    {"gst_rate": 18.0, "invoice_count": 5, "taxable_value": 50000.0, "cgst": 4500.0, "sgst": 4500.0, "igst": 0.0, "total_tax": 9000.0}
  ],
  "totals": {
    "invoice_count": 7,
    "taxable_value": 60000.0,
    "cgst": 4750.0, "sgst": 4750.0, "igst": 0.0,
    "total_tax": 9500.0
  }
}
```

Logic: Query `invoice_lines` joined to `invoices`, group by `gst_rate`, sum up amounts. Only include invoices with status in `("sent", "paid", "overdue")`.
