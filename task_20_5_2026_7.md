## Part 2 — Real Attendance

### 2a. New `models/attendance.py`

```python
class AttendanceRecord(Base):
    __tablename__ = "attendance_records"

    id:           Mapped[int]            = mapped_column(Integer, primary_key=True)
    workspace_id: Mapped[int]            = mapped_column(ForeignKey("workspaces.id"), nullable=False, index=True)
    user_id:      Mapped[int]            = mapped_column(ForeignKey("users.id"), nullable=False, index=True)
    check_in:     Mapped[datetime]       = mapped_column(DateTime, nullable=False)
    check_out:    Mapped[Optional[datetime]] = mapped_column(DateTime, nullable=True)
    worked_hours: Mapped[Optional[float]]   = mapped_column(Numeric(6, 2), nullable=True)
    date:         Mapped[date]           = mapped_column(Date, nullable=False, index=True)
    # date = check_in.date(), stored for fast monthly reports
```

**Schemas:**
```python
class AttendanceRecordOut(BaseModel):
    id:           int
    user_id:      int
    check_in:     datetime
    check_out:    Optional[datetime]
    worked_hours: Optional[float]
    date:         date
    model_config = {"from_attributes": True}

class AttendanceStatus(BaseModel):
    attendance_state: str    # 'checked_in' | 'checked_out'
    last_check_in:    Optional[datetime]
    open_record_id:   Optional[int]

class TeamMemberStatus(BaseModel):
    id:               int
    name:             str
    attendance_state: str
    last_check_in:    Optional[datetime]
    worked_hours_today: Optional[float]
```

**Endpoints:**

```
GET /attendance
    Query: limit (default 30, max 90)
    Where: workspace_id == ws, user_id == current_user.id
    Order: check_in DESC
    Returns: list[AttendanceRecordOut]

GET /attendance/status/{user_id}
    Returns AttendanceStatus for the given user (in current workspace)
    Open record = where check_out IS NULL
    attendance_state = 'checked_in' if open record exists else 'checked_out'
    last_check_in = open record's check_in datetime

POST /attendance/check-in
    If user already has an open record (check_out IS NULL): return 409 "Already checked in."
    Create AttendanceRecord(
        workspace_id=ws, user_id=current_user.id,
        check_in=datetime.utcnow(), date=date.today()
    )
    Returns AttendanceStatus

POST /attendance/check-out
    Find open record for current user (check_out IS NULL)
    If none: return 409 "Not currently checked in."
    now = datetime.utcnow()
    record.check_out = now
    record.worked_hours = round((now - record.check_in).total_seconds() / 3600, 2)
    Returns AttendanceStatus

GET /attendance/team
    For each active user in the workspace, return their name + current status.
    Query: JOIN users on workspace_id, then left join latest open attendance record.
    Simple approach:
      1. Fetch all active users in workspace
      2. For each user, fetch their open record (check_out IS NULL) if any
    Returns list[TeamMemberStatus]
    (N+1 is acceptable for typical team sizes < 100)
```

**Key constraint:** `check-in` rejects if there's already an open record. This prevents double
check-ins if the page is clicked twice.
