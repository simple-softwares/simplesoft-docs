# Session 5 Task — Dashboard Upgrade + Print/PDF Views + Quote→Invoice Conversion
**Date:** 2026-05-20

---

## Why These Three

The ERP core is functionally complete but the product doesn't *feel* complete yet because:
1. **Dashboard shows zero financial data** — 5 stat tiles only count tasks/projects/contacts. Revenue, AR, overdue, cash position are invisible.
2. **No way to print or download an invoice or quotation** — users need a PDF to send to customers. Biggest missing UX piece.
3. **Quotation "Confirm Order" is a dead end** — clicking it sets status to "confirmed" but there's no "Create Invoice" button, breaking the sales cycle.

All three are completeable without new models or major refactoring.

## Part 1 — Dashboard Upgrade

### Backend: Extend `routers/dashboard.py`

**New endpoint: `GET /dashboard/erp`**

Runs 8 fast aggregation queries in parallel across invoices, accounting, and quotations. Returns a single JSON object.

```python
@router.get("/erp")
async def get_erp_dashboard(
    current_user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
):
```

Required imports to add: `Invoice`, `JournalEntry`, `JournalEntryLine`, `ChartOfAccount`, `Quotation`

**Queries (all filter by `workspace_id`):**

```
invoiced_this_month:  SUM(Invoice.total)
                      WHERE invoice_date in current month AND status IN ('sent','paid','overdue')

paid_this_month:      SUM(Invoice.total)
                      WHERE invoice_date in current month AND status = 'paid'

outstanding_ar:       SUM(Invoice.total)
                      WHERE status IN ('sent','overdue')

overdue_amount:       SUM(Invoice.total)
                      WHERE status = 'overdue'

overdue_count:        COUNT(*) WHERE status = 'overdue'

gst_due_this_month:   SUM(cgst_total + sgst_total + igst_total)
                      WHERE invoice_date in current month AND status IN ('sent','overdue')

cash_position:        For account_code='1002' (Bank - Current):
                      SUM(debit) - SUM(credit) across all JournalEntryLines
                      joined to JournalEntries in this workspace
                      (uses _account_balances logic from accounting router)

open_quotes:          COUNT(*) of Quotations WHERE status IN ('draft','sent')

recent_invoices:      5 most recent Invoices by created_at (return id, invoice_number,
                      customer_name, total, status, invoice_date)
```

Response shape:
```json
{
  "invoiced_this_month": 125000.00,
  "paid_this_month": 80000.00,
  "outstanding_ar": 45000.00,
  "overdue_amount": 12000.00,
  "overdue_count": 3,
  "gst_due_this_month": 22500.00,
  "cash_position": 350000.00,
  "open_quotes": 5,
  "recent_invoices": [
    {"id": 12, "invoice_number": "INV-2026-00012", "customer_name": "ABC Ltd",
     "total": 25000.00, "status": "sent", "invoice_date": "2026-05-18"}
  ]
}
```

For `cash_position`: query `JournalEntryLine` joined to `JournalEntry` filtered by `workspace_id`, then look up the `ChartOfAccount` with `account_code = '1002'`. If no such account exists, return 0.

## Part 2 — Invoice + Quotation Print Views

### New component: `pages/invoicing/InvoicePrintPage.jsx`

Route: `/invoices/:id/print`
Layout: Renders WITHOUT the AppLayout sidebar — raw `<div>` root only.

Design:
- White background, A4 proportions, `max-w-3xl mx-auto p-12`
- Top: company name (from `GET /gst/config`), GSTIN, address on left; "TAX INVOICE" heading + invoice number + date on right
- Bill To box: customer name, GSTIN, address
- Line items table: Description | HSN | Qty | Unit Price | GST% | CGST | SGST (or IGST col if inter-state) | Total
- Section lines: grey shaded row spanning all columns (section heading)
- Note lines: italic text spanning all columns
- Totals box (right-aligned): subtotal, discount, CGST, SGST/IGST, **Total in bold**
- Footer: Notes + Terms & Conditions
- Print button (top right, hidden from print via `@media print { .no-print { display: none } }`)
- Status banner (hidden from print): if `status === 'draft'` show a "DRAFT — NOT A VALID TAX INVOICE" watermark diagonal text

**CSS trick for PDF:**
```jsx
// In the component, add this to trigger print:
const handlePrint = () => window.print();
```
Add `<style>{`@media print { .no-print { display: none !important; } body { background: white; } }`}</style>`

## Part 3 — Quotation → Invoice Conversion

### Frontend only — update `QuotationDetailPage.jsx`

When `quote.status === 'confirmed'`, show a "Create Invoice" button that navigates to:
```
/invoices/new?from_quote={id}
```

### Update `InvoiceFormPage.jsx`

On mount, read `?from_quote` search param. If present:
1. Call `GET /quotations/{from_quote}` 
2. Pre-fill: `customerName`, `customerGstin`, `customerAddress`, `customerId`, `placeOfSupply`
3. Pre-fill lines: only `line_type === 'product'` lines from the quotation (skip sections/notes)
4. Map fields: `description`, `hsn_code`, `qty`, `unit_price`, `discount_amount`, `gst_rate`
5. Show a blue info banner: "Pre-filled from Quotation {quote_number}. Review and save as draft."

This is pure frontend — no new API endpoint needed. The quotation data comes from existing `GET /quotations/{id}`.
